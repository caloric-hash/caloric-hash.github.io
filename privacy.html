Avalon Mail privacy policy

Last updated: 22 November 2026

Avalon Mail is a personal tool used only by its owner, on the owner's own computer, with the owner's own Google accounts.

What it accesses

With the owner's consent, it reads Gmail messages using Google's read-only Gmail permission (gmail.readonly). It cannot send, delete or change mail.

How data is used and stored

  • Mail is fetched directly from Google to the owner's computer and shown only to the owner.
  • Sign-in tokens are stored only on that computer.
  • No data is sold, shared with third parties, or used for advertising.
  • No data is sent to any server run by Avalon Mail; there is none.

Google API Services User Data Policy

Avalon Mail's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.
