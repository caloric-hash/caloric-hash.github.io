Privacy policy

BIRDS NEST is a private home dashboard used by its owner on their own computer. This page explains what it does with Google data.

What it reads

With the owner's permission, it reads their Google Calendar events, including birthdays and holidays, using Google's read-only calendar access. It does not ask for any other Google data.

How it is used

Events are shown on the dashboard's calendar card and nowhere else. BIRDS NEST never creates, changes or deletes calendar events.

Where it is kept

Everything stays on the owner's computer. The sign-in key is stored in a private file there. No data is sent to any server other than Google's own, and nothing is sold, shared or used for advertising.

Google API Services

BIRDS NEST's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Stopping access

The owner can remove access at any time from their Google Account, under Security, then Third-party apps and services, or by choosing "Use a different app" on the dashboard's calendar card, which deletes the stored key.
